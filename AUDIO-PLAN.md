# Talent Jackpot — звук (план и состояние на 25.09.2026)

Процедурный звук из `src/audio/sfx.ts` заменён CC0-сэмплами (Freesound, Kenney). Синтезированным остался только
тик стрелки колеса: он понравился как есть. Источники — в `CREDITS.md`, карта файлов — в `src/audio/manifest.ts`,
**громкость всех звуков — в `src/audio/volumes.ts`** (в `npm run dev` правки применяются на лету).

## Решения

- Стиль — классический казино / Вегас-слот. Фон основной игры — тихий шум ночного офиса.
- Сила выигрыша — по уровню в пуле (`rarityInPool`): Match / Strong match / UNICORN; один звук на спин, по `wins[0]`.
- Пустой спин и «почти» (2 навыка) — **без звука**. Грустная труба звучит только при проигрыше на колесе торга.
- Anticipation при двух папках — **не делаем**.
- Утешительного приза за проигранный бонус **больше нет** (ни кредитов, ни звона монет). Утешение осталось
  только когда бонус выигран, но пул кандидатов пуст.
- Касса (`credits`) звучит один раз на старте докрутки кредитов; обмен и «Beg HRD» — `cash`.
- В настройках: тумблер «Sound» (общий mute) и ползунки Volume (общая), Music (музыка + фон), Effects (эффекты + интерфейс).

## Устройство

- `engine.ts` — один `AudioContext` (создаётся на первом жесте), ogg или mp3 по `canPlayType`, путь через `BASE_URL`,
  сначала грузится `CRITICAL`, остальное в фоне; неготовый звук тихо пропускается, луп стартует, как только готов.
  У mp3-лупов тишина энкодера по краям срезается автоматически.
- Шины `music`, `ambient`, `sfx`, `ui`; приглушение (ducking) — уровни в `DUCK` (`volumes.ts`).
  Mute опускает master в 0, лупы продолжают идти — музыка подхватывается при включении.
- Настройки: `hrgacha:settings.v3` + `masterVol`, `musicVol`, `sfxVol` (`migrateSettings` в `store.ts`).

## Основная игра

| Событие | Звук |
| --- | --- |
| Первый жест | `ambient`, луп, fade-in 2 с |
| Рычаг / SPIN / пробел | `lever` |

| Остановка барабана | `reel-stop` |
| Золотая папка на барабане | `scatter`; один звук на барабан; каждая следующая за спин на 2 полутона выше |
| Встали все барабаны, 3+ папок | `bonus-enter` (фанфары) через 0,3 с; затухают, когда открывается окно миниигры |
| Выигрыш | `WIN_SOUND[wins[0].rarity]` |
| ±линии, пресеты, автоспин | `button` (щелчок клавиши) |
| Линия стала последней включённой (+/−, клавиатура, пресет) | `line-note` (маримба) на высоте `PAYLINES[N−1].note` + `LINE_NOTE_SHIFT`: мажорная гамма, вверх при добавлении, вниз при убирании; пресет — только нота конечной линии |

| Докрутка кредитов вверх | `credits`, один раз |
| Обмен на кредиты, «Beg HRD» | `cash` |
| Открыть резюме / в шорт-лист | `shortlist` (штамп) |

## Бонус «Золотая папка»

- Музыка `bonus-music` (Talk Show 02): вступает через 0,5 с, приглушена фильтром; когда до исхода один шаг —
  фильтр открывается, громче и быстрее (`BONUS_MUSIC`). API `music.start/stop/setIntensity` сохранён.
- Папки: Матч `folder-match`, Отказ `folder-miss`, Пустая `folder-noshow`, Защита `folder-shield` — один звук в момент разворота.
- Победа (третья папка с матчем) — `win-unicorn`, один раз; при открытии карточки кандидата звука нет.
- Проигрыш — без звука и без кредитов.

## Колесо торга

- Музыка `wheel-music` (quiz game music loop, викторина) — сразу при открытии, без заставки. С каждой выигранной ступенью фильтр
  приоткрывается и темп растёт на 2 % (до 1.1) — `WHEEL_MUSIC`. При выходе из колеса затухает.
- Тик стрелки — синтезированный щелчок (`WHEEL_TICK_VOLUME`).
- Зелёный сектор — `wheel-win` (WinBrass); потолок (финальная победа) — фанфары `win-unicorn`; плашки навыков, долетая до табло, — `scatter` с повышением.
- Жёлтый (респин) — `wheel-respin`.
- Красный (GHOSTED) — музыка обрывается, грустная труба `almost`.
- ЗАБРАТЬ / НАЗАД — обычный щелчок `button`. Неактивные кнопки колеса (КРУТИТЬ на потолке, всё во время вращения) — глухой `line-limit`.
